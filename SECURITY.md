# Segurança

O Prompt Bench armazena experimentos no `localStorage` do navegador e não envia prompts ou respostas para serviços externos no MVP.

Não publique chaves de API, segredos ou dados confidenciais em issues, exemplos ou Pull Requests. Para reportar uma vulnerabilidade, descreva versão, passos mínimos de reprodução e impacto sem incluir dados sensíveis.
