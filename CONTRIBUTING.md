# Como contribuir

1. Abra uma issue descrevendo o problema ou melhoria.
2. Crie uma branch a partir de `main`.
3. Faça mudanças pequenas e focadas.
4. Adicione ou atualize testes.
5. Execute `npm run check` e `npm test`.
6. Abra um Pull Request explicando motivo, impacto e validação.

Não inclua prompts, respostas, chaves de API, dados pessoais ou informações corporativas reais nos exemplos e testes.
